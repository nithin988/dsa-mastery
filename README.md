# DSA Mastery

Pattern-based Data Structures and Algorithms revision sheets for interview preparation. One self-contained HTML page per topic, each with intuition, step-by-step traces, code, complexity, common traps and a ladder of LeetCode problems.

See [ROADMAP.md](ROADMAP.md) for the full topic list and build status.

Topics are added one at a time. Each page has a Download button so it can be saved and read offline.
